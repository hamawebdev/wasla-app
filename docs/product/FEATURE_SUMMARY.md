# Wasla — Feature Summary (Executive)

An at-a-glance summary of everything Wasla offers, grouped by category, with a status for each feature and a short explanation.

## Status legend

| Status | Meaning |
|---|---|
| 🟢 **Available** | Fully present and usable in the app. (Some run on sample data or simulated processing in the current build, as noted.) |
| 🟡 **Partially Available** | Present but limited — part of the experience is simulated, static, or pending integration. |
| 🔵 **Coming Soon** | Indicated in the app as planned but not yet usable. |

> Per the product direction, features are described as the intended product. Status reflects how complete each one is in the current build.

## Status notes

The following capabilities are presented as part of the intended product but currently rely on sample data or simulated steps:

- **Sign-in (account picker & OTP):** any verification code is accepted, and demo accounts provide instant access.
- **Social sign-in:** Google/Facebook buttons are present but not wired to a provider.
- **Payments, wallet top-up/withdrawal, and direct-purchase promotion:** confirmed via on-screen messages with sample data.
- **Share** (service) and **subcategory refinement**: indicated in the UI, pending full implementation.
- **Profile photo upload:** explicitly flagged as coming in a future update.

All other features listed as 🟢 Available behave as described, operating on the app's built-in demo catalogue of providers, services, bookings, chats, and rewards.
